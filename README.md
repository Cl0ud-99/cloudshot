# Cloudshot · 轻截图

一个 Windows 常驻托盘的轻量截图工具。按下快捷键，屏幕被冻结并压暗，框选区域后可直接标注，按 `Enter` 复制到剪贴板 —— 和微信截图的手感一致。

- **单文件 exe，约 76 KB**，双击即用，不需要安装运行时（依赖系统自带的 .NET Framework 4.8，Win10 1903+ / Win11 都有）
- **常驻托盘**，不占任务栏、不出现在 Alt+Tab
- **全局热键** 默认 `Alt + A`，可在设置里改成任意组合键
- **覆盖任意窗口**：置顶全屏遮罩，任务栏、浏览器、IDE 之上都能截
- **截图即复制**：确认后图片直接进剪贴板，不落盘，`Ctrl + V` 就能粘贴
- **窗口自动识别**：鼠标停在哪个窗口，就高亮哪个窗口，单击直接截取（和微信一样）
- **取色放大镜**：拖动时跟随光标显示 8 倍放大画面、十字准星、像素坐标与 `#RRGGBB` 取色值
- **一键取色复制**：停在任意像素上按 `C`，色值直接进剪贴板并弹出提示，遮罩不关，可连续取多个色
- **选区翻译**：框选文字后按 `T`（或点工具栏「翻译」），自动 OCR + 中英互译，浮层显示原文与译文，可一键复制
- **框选取字**：框选后按 `O`（或点工具栏「取字」）进入取字模式，鼠标变成 I 形文字光标，像选文本一样**拖动选择任意片段**，`Ctrl+C` 只复制选中的部分；识别前会把小图放大 2 倍以提升小字号准确率
- **零网络**：不联网、不上传、不写注册表以外的任何东西

## 使用

| 操作 | 说明 |
| --- | --- |
| `Alt + A` | 唤起截图（默认热键） |
| 移动鼠标 | 自动高亮光标下的窗口，并在角上显示窗口尺寸 |
| 单击 | 直接截取高亮的窗口并复制到剪贴板（立即完成，不进标注界面） |
| 拖动 | 框选任意区域；框好后可拖八个控制点微调，或按住内部拖动整体移动 |
| 控制点（任意工具下） | 八个控制点**始终可拖**，开着标注工具也能改选区大小 |
| `Ctrl` + 拖动 | 开着标注工具时整体移动选区；**按下 Ctrl 的瞬间光标就变成移动箭头**，松开恢复 |
| `1` ~ `6` | 切换标注工具：矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 |
| 点击色块 | 切换标注颜色（红、橙、黄、绿、蓝、白） |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `C` | 复制光标处的颜色值（`#RRGGBB`），遮罩不关，可连续取色 |
| `T` 或工具栏「翻译」 | 识别选区文字并翻译，浮层显示原文/译文；`Ctrl+C` 复制译文 |
| `O` 或工具栏「取字」 | 进入/退出取字模式；拖动选字，`Ctrl+C` 复制选中部分 |
| 工具栏 `A−` / `A+` | 调整文字标注字号（10–120px，中间显示当前值） |
| 文字工具下拖动已有文字 | 移动这段文字的位置 |
| `+` / `-` | 文字工具激活时调整字号；否则调整取字的 OCR 放大倍率（1–4×） |
| `Enter` | 确认，图片进入剪贴板（无提示音、无弹窗） |
| `Esc` / 右键 | 取消 |

文字工具：选「文字」后点一下画面即可打字，`Enter` 结束输入（若输入法候选框开着，`Enter` 先上屏，再按一次才结束）。

托盘图标：左键双击立即截图；右键菜单包含「截图 / 设置 / 开机自动启动 / 退出」。

## 开机自启

两种方式，效果相同（优先写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员权限）：

1. 右键托盘图标 → 勾选「开机自动启动」
2. 托盘右键 →「设置...」→ 勾选「开机自动启动」

如果注册表写入被组策略或安全软件拒绝，程序会自动退回到「启动」文件夹里的快捷方式（`shell:startup`），设置里会显示当前用的是哪种机制。两种都被拒绝时，会弹窗说明原因，并可以直接打开「启动」文件夹手动放快捷方式。

取消勾选即移除启动项（注册表值和快捷方式会一起清掉）。软件是绿色版，卸载 = 退出程序 + 删除 exe + 取消开机自启。

> **注意**：请把 `Cloudshot.exe` 放在普通目录（桌面、`C:\Tools` 等）。放在某些受保护或沙箱化的目录里时，系统会拒绝该进程写注册表和用户配置目录，此时开机自启无法设置（截图功能本身不受影响）。

## 自定义快捷键

托盘右键 →「设置...」→ 点击快捷键方框 → 按下新组合键（至少包含 Ctrl / Alt / Shift / Win 之一，或使用 F1–F12）。新热键立刻生效；若被其他程序占用，会自动回滚到原快捷键并提示。

## 命令行参数

```text
Cloudshot.exe                    启动并常驻托盘
Cloudshot.exe --capture          启动后立刻进入截图
Cloudshot.exe --settings         启动后直接打开设置窗口
Cloudshot.exe --autostart-on     写入开机自启后退出（可脚本化部署）
Cloudshot.exe --autostart-off    移除开机自启后退出
Cloudshot.exe --set-youdao ID 密钥   保存有道翻译凭据（DPAPI 加密）后退出
Cloudshot.exe --translate-test 图片.png  对图片跑一次 OCR+翻译，结果写到同目录 translate-test.txt
Cloudshot.exe --diag             写一份运行环境诊断到 exe 同目录的 diag.txt
```

重复启动不会开第二个实例，而是唤起已有实例立即截图。

## 从源码构建

需要 .NET SDK 8（仅构建用，产物仍是 .NET Framework 4.8 程序）：

```powershell
dotnet build Cloudshot.csproj -c Release
# 产物：bin\Release\net48\Cloudshot.exe
```

工程刻意不使用 XAML：全部界面由 C# 代码构建，因此不需要 Visual Studio 的 WPF 标记编译器，`dotnet build` 一条命令即可出包。

### 结构

## 实现要点

- **先抓图再显示**：遮罩出现前已完成 `CopyFromScreen`，所以永远不会把自己或托盘提示拍进去；提示层收起后还有 140 ms 的缓冲。
- **窗口识别只枚举一次**：遮罩铺满屏幕、画面已冻结，窗口不会在截图过程中移动，所以进入截图时按 Z 序枚举一遍顶层窗口（用 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` 取可见边界，避开不可见的调整边框），之后每帧只做矩形命中测试。
- **像素坐标系**：窗口按物理像素布局（`LayoutTransform` 反向缩放），选区、标注、导出全部在 1:1 像素空间，导出用 `RenderTargetBitmap` 直接绘制模型，所见即所得。
- **标注不落到 UI 元素**：所有标注是纯数据模型 + 一个自绘 `FrameworkElement`，撤销重做只是增删列表，不会越用越卡。
- **马赛克是真像素化**：按 12×12 方块对选区原图取平均后重绘，再用笔画轮廓裁剪，导出图片里也是马赛克，不是预览用的假效果。
- **热键强抢前台**：`AttachThreadInput` + `SetForegroundWindow`，保证按完热键马上能 `Esc` 取消，不用先点一下画面。
- **右键取消不穿透**：取消动作放在鼠标**松开**时执行（按下只吞掉事件），窗口照常立即关闭；随后 250 ms 内用低级鼠标钩子（`WH_MOUSE_LL`）吞掉所有右键事件，避免漏到下面的页面弹出右键菜单。钩子到期自动卸载，不改变任何画面状态，所以没有闪烁。
- **OCR 用系统引擎**：调用 Windows 自带的 `Windows.Media.Ocr`（离线、免费、不打包模型），会枚举系统里**所有已安装**的识别语言逐个识别，再按字符构成挑最可信的一份；要求系统装有对应语言的 OCR 包。
  安装更多语言（管理员 PowerShell，每个约 30–60MB）：

  ```powershell
  Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"   # 日文
  Add-WindowsCapability -Online -Name "Language.OCR~~~ko-KR~0.0.1.0"   # 韩文
  Add-WindowsCapability -Online -Name "Language.OCR~~~fr-FR~0.0.1.0"   # 法文
  Add-WindowsCapability -Online -Name "Language.OCR~~~de-DE~0.0.1.0"   # 德文
  ```
- **翻译签名**：有道 v3 规则 `SHA256(appKey + 截断文本 + salt + curtime + appSecret)`，`curtime` 必须是 **UTC 秒级时间戳**（用本地时间会报 206）。凭据用 Windows DPAPI 按当前用户加密存储。

## 已知限制

- 全屏独占（exclusive fullscreen）的 DirectX 游戏无法截取，普通窗口、无边框全屏、浏览器都可正常截取。
- 多显示器且各屏 DPI 不同（混合 DPI）时，第二次拖动可能仍按主屏缩放换算，属于已知边缘情况；单屏或统一缩放不受影响。
- 剪贴板只放位图，不自动存文件（按需求如此）。需要留档时请在粘贴后自行保存。
- 系统若禁用了托盘图标（组策略），程序仍在运行，可用 `Cloudshot.exe --capture` 直接截图。

## 在其他电脑上使用（Win10 / Win11 换机）

程序是**单文件绿色版**，只依赖系统自带的 .NET Framework 4.8（Win10 1903+ / Win11 全部内置），不需要安装任何运行时。但换机时有 6 个点要注意：

1. **放在普通目录**：桌面、`C:\Tools` 等都行；不要放在受保护/沙箱目录（否则写配置和开机自启会被拒）。
2. **翻译 Key 不会跟着走**：配置在 `%APPDATA%\Cloudshot\settings.ini`，密钥用当前用户的 DPAPI 加密，换电脑 / 换用户都解不开。新机器要在「设置 → 翻译服务」重新填一次 App ID 和密钥，点「测试翻译」确认。
3. **开机自启要重新勾选**：注册表项指向的是旧路径，复制到新位置后在托盘菜单里重新勾选一次。
4. **补装 OCR 语言包**：新系统默认可能只有显示语言的 OCR。取字/翻译要用的语言，用管理员 PowerShell 装：

   ```powershell
   Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"   # 英文
   Add-WindowsCapability -Online -Name "Language.OCR~~~zh-CN~0.0.1.0"   # 中文
   ```

5. **SmartScreen 提示**：exe 没有代码签名，从网上/邮件拷过来首次运行可能弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。
6. **高 DPI**：Win11 常见 125% / 150% 缩放，程序已声明 Per-Monitor V2；单屏下正常，**多屏混合 DPI** 仍属未完全验证的边缘情况，若发现选区整体偏移，告诉我具体缩放组合我来修。

另外两点环境相关：Win11 开启 **HDR** 时截图可能偏灰（系统色彩管理所致）；`Alt+A` 可能与别的软件冲突，冲突时到设置里改热键。

## 排障

- 快捷键没反应：可能被其他程序占用。托盘右键 →「设置」→ 改一个组合键；或看托盘气泡提示。
- 翻译失败：设置页点「测试翻译」会显示真实原因。常见的有道错误码——`108` 应用未开通文本翻译服务、`202` 密钥与该应用 ID 不匹配、`206` 本机时间不准（校准系统时间）、`411` 调用频率受限。
- 翻译识别不到文字：选区里是纯图形或字号太小。把选区框大一点，或先用 `1–6` 标注工具放大查看。
- 提示「写入开机启动项失败 / 访问被拒绝」：说明当前进程被系统或安全软件限制了注册表写入。先把 exe 移到普通目录再试；程序也会自动尝试「启动」文件夹快捷方式。用 `Cloudshot.exe --autostart-on` 可复现同样的判断逻辑。
- 想看错误日志：`%APPDATA%\Cloudshot\error.log`（仅在异常时产生）。
- 想看待办日志：`%APPDATA%\Cloudshot\debug.log`（每次唤起/关闭遮罩记一行，排查“热键没反应”时有用）。
- 想看运行环境：`Cloudshot.exe --diag`，会在 exe 旁生成 `diag.txt`。
